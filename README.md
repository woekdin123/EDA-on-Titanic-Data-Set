The Titanic dataset is popular for data analysis .
It contains information about the passengers onboard the Titanic, including features like age, gender, fare, cabin, and
survival status.
We will perform exploratory data analysis (EDA) on the Titanic dataset using Python in this project.

# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA)
This repository contains an Exploratory Data Analysis (EDA) of the famous Titanic dataset. The goal is to understand the data, uncover patterns and relationships, and generate insights that can help in predictive modeling, especially survival prediction.

## 📂 Dataset
The Titanic dataset is available from Kaggle Titanic Competition.

## Main files:
train.csv: Data used for training (contains Survived column).

test.csv: Data used for testing predictions (no Survived column).

## 📊 EDA Objectives
Understand the structure and types of the data

Handle missing values

Analyze key features that influence survival

Explore relationships between variables (e.g. age, gender, class)

Visualize distributions and trends

Prepare data for machine learning (feature engineering basics)

## 🔍 Key Insights
Gender: Females had a much higher survival rate than males.

Class: Passengers in higher classes had better chances of survival.

Family Size: Passengers with small families (1–3 members) had better survival rates.

Embarked Port: Slight variation in survival rates depending on the port of embarkation.

Age: Younger passengers had slightly higher survival probabilities.
